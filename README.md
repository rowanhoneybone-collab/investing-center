# Investing Center

**Investing Center** is the active successor to Market Espresso: a personal market-intelligence dashboard that keeps the original Morning Brew-style daily briefing while adding deeper research and decision-support tools.

The original `market-espresso` repository is intentionally preserved as the Market Espresso V1 archive. New feature development should happen here.

## Current modules

- **Today / Market Espresso** — daily market snapshot, five things to know, portfolio pulse and upcoming catalysts.
- **Portfolio** — current configured holdings with live price context and links into company research.
- **Company Intelligence** — research sheets for tracked companies with business context, live quote, market cap, valuation/quality metrics when available, earnings, peers and news.
- **Catalyst Calendar** — tracked-company earnings, portfolio dividend dates, FOMC decisions, CPI, employment, PCE/GDP and EIA petroleum reports.
- **Markets** — broad U.S. index proxies and current market headlines.
- **Sectors** — broader competitive landscape around Energy, AI + Healthcare, Industrials and Consumer + Media.
- **Fed & Bonds** — official Fed target range, U.S. Treasury curve, daily basis-point changes and rates headlines.
- **Dividends** — upcoming ex-dividend events returned for configured holdings.

## Live data

The site is generated by `.github/workflows/refresh.yml` and deployed with GitHub Pages. The workflow runs hourly during a broad U.S. weekday market window and once daily on weekends.

Official Fed and Treasury information does **not** require an API key. Live market quotes, company profiles/basic financials, earnings, dividends and market/company news use Finnhub.

### Required repository secret

Create this Actions secret in the `investing-center` repository:

`FINNHUB_API_KEY`

Use the same Finnhub key that powers the archived Market Espresso app. GitHub repository secrets do not automatically copy between repositories.

## GitHub Pages

In **Settings → Pages**, set the source to **GitHub Actions** if it is not already enabled. Then run **Actions → Refresh Investing Center → Run workflow** once.

Expected Pages URL:

`https://rowanhoneybone-collab.github.io/investing-center/`

## Data sources

- Finnhub for quotes, company profiles, basic financials, earnings, dividends and news.
- U.S. Department of the Treasury for the Daily Treasury Par Yield Curve.
- Federal Reserve for monetary-policy releases and FOMC information.
- BLS/BEA/Federal Reserve official release calendars for configured U.S. macro catalysts.
- U.S. EIA for the Weekly Petroleum Status Report schedule.

Research and education only; not investment advice.
